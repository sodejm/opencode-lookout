# Governance

OpenCode Lookout is maintained by [@sodejm](https://github.com/sodejm). It is an
independent community extension. The maintainer owns scope, compatibility,
dependency, security, and release decisions.

Use issues for proposals and pull requests for reviewable changes. Explain the
problem and relevant trade-offs before proposing broad API or configuration
changes. The maintainer makes the final decision and records material decisions
in the issue, PR, or affected architecture documentation.

The maintainer may review and merge their own contributions; a second reviewer is
not required. Automated checks and AI reviews supplement human review, not replace
it. Human review must cover the exact revision and its failure/recovery behavior.

The repository is public, but npm publication is deliberately disabled. There is
no automatic release workflow. A future release needs a versioned changelog,
current validation evidence, security review, and a deliberate maintainer decision.
Pushing a commit is not a release or proof of compatibility with a new OpenCode
version. MIT governs reuse; this document governs project contributions.
